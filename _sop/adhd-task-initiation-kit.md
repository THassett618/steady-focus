## hook-01 Dream/Pain Stack

- Product: 4 printable pages (how to use, Micro-Step Breakdown, 5-Minute Start Timer, One Task at a
  Time). Target customer: someone who knows the task and still can't start it.
- Competitors: to-do apps and lists (Finch, Tiimo named in App Store rows 121-123). They store the
  goal. Buyers complain about order and nagging ("they all get completely out of order", "annoying
  reminders ... every 4 minutes"). The task-breakdown feature is the part a Tiimo reviewer praised (123).
- Mechanism: the page only asks for the first physical move and a 5-minute promise. "Standard to-do
  lists ... list what needs to be done without addressing how to start" (116).
- DREAM = actually starting. PAIN = staring at the list feeling lazy.
- Ranked hooks:
  1. Your to-do list isn't missing tasks. It's missing the first move.  ← **H1**
  2. Stop writing "clean kitchen." Write "pick up the first cup."
  3. Starting is the hard part. This kit only does starting.
  4. Five minutes is a promise you can keep.

## hook-02 three triggers

- Discovery: the line every to-do list skips is the first physical action.
- Dream without nightmare: start the task without needing a burst of motivation.
- Effortless: write one action, set five minutes, stop when it rings if you want.

## hook-03 bullets (top 4, on the page)

1. **Micro-Step Breakdown**: the task's first three physical actions. Actions, not goals.
2. **5-Minute Start Timer**: when it ends you may stop. Starting counts as the win.
3. **One Task at a Time**: a parking lot for everything that tries to interrupt you.
4. **How to use**: the whole method on one page.
