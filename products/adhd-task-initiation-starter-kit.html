The problem this is for

You know the task. It is written down. You still have not started. Writing "clean kitchen" is a goal, not a first move. Two sources we read put it this way:

"Standard to-do lists typically fail people with ADHD because they list what needs to be done without addressing how to start."Hello Klarity, "Breaking the first step barrier"
"Commit to working on something for just five minutes. This can sidestep internal resistance and build momentum naturally."Tiimo, task initiation guide

Those are general tips from other sites. Our kit is simply a printable way to use them: a page that makes you write the first move, a page that holds the five minutes, and a card that keeps one task in view.

What is inside

  1. How to use (a one-minute quick start)
  2. Micro-Step Breakdown: turns one big task into its first physical move
  3. Five-Minute Start Timer: a commitment small enough to keep
  4. One-Task-at-a-Time card: keeps the list from growing back while you work

Delivered as one combined PDF plus separate files.

How it is meant to be used

  • Pick the one task you have been putting off.
  • Write the very first move on the Micro-Step Breakdown ("pick up the first cup", not "clean kitchen").
  • Start the five minutes. You are allowed to stop when they end.

Who it is not for

  • If your problem is planning the whole week, this is too narrow. See the ADHD Focus Bundle.
  • It will not make a task less boring. It only makes the first step smaller and clearer. Some people will find that is enough and some will not.
  • It is paper. If you want a phone app that does task breakdown for you, there are good ones; see the comparison guide.
